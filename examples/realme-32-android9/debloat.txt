# Realme 32 inch Smart TV (Android 9 / API 28)
# Based on Realme 32 inch Android TV with Android 9
# 1 GB RAM (MemTotal about 935 MB). Stock launcher: com.google.android.tvlauncher
# Live TV / tuner: com.mediatek.wwtv.tvcenter (leave it; the Inputs menu uses it)
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/realme-32-android9/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/realme-32-android9/debloat.txt com.google.android.tvlauncher
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Known quirks on this firmware:
# - USB debugging alone opens network ADB on port 5555
# - After a reboot the TV may take a new DHCP address
# - Private DNS dns.adguard-dns.com validates and survives a reboot
